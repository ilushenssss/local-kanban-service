# Канбан

Отдельное настольное приложение Python + PyQt5 для закрытой локальной сети. Без сайта, сервиса, регистрации, облачных API и загрузок при запуске. Роли пока не используются. Автор изменений — имя пользователя Windows.

## Версия 1.5

Доски переключаются вкладками сверху. «Мои задачи» показывает назначения по всем активным доскам с поиском и фильтрами. Карточки и двухколоночное окно задачи переработаны по присланному образцу YouGile.

Во вкладке «Статистика» добавлены графики завершения, распределения по колонкам и нагрузки сотрудников. Точные значения доступны на вкладке «Таблицы». Графики работают без интернета и дополнительных зависимостей.

Обновление доски не пересоздаёт колонки во время перетаскивания и при неизменившихся данных. После переноса загружается актуальное состояние.

Интерфейс с ориентиром на канбан YouGile: цветные заголовки, границы колонок, компактная навигация, дополнительные фильтры под кнопкой «Фильтры». Задачу можно создать прямо в нужной колонке.

- **Колонки → выбрать строку → Удалить колонку…**: выберите, куда перенести задачи, подтвердите и сохраните настройки. Переносятся также архивные задачи; история сохраняется. Последнюю колонку удалить нельзя.
- Метки имеют постоянные автоматические цвета на карточках и в списках выбора.
- Вкладка **Статистика**: все неархивные задачи выбранной доски, завершение, просрочка, распределение по колонкам и сотрудникам. Поисковые фильтры на статистику не влияют.
- Внизу навигации — переключатель **Тёмная тема / Светлая тема**. Выбор сохраняется на компьютере сотрудника.

Перед обновлением закройте приложения у всех сотрудников, создайте резервную копию, сохраните `data/` и `kanban.ini`. Обновите программу на всех рабочих местах.

## Лёгкое обновление — ветка updates

Эта ветка содержит все файлы проекта **кроме папки `environment/` со встроенным Python**. Она предназначена для обновления уже установленного приложения.

[Скачать лёгкий ZIP](https://github.com/ilushenssss/local-kanban-service/archive/refs/heads/updates.zip)

1. Закройте приложение у всех сотрудников и сделайте резервную копию данных.
2. Распакуйте ZIP во временную папку. Откройте внутри папку `local-kanban-service-updates`.
3. Скопируйте **её содержимое** в существующую папку приложения, подтвердив замену файлов. Не удаляйте прежнюю папку приложения и не подменяйте её целиком.
4. Сохраните существующие `environment/`, `data/` и `kanban.ini`. В архиве обновления их нет.
5. Запустите приложение прежним ярлыком. Если перенесли приложение в другое место, заново запустите `Create-shortcut.vbs`.

При установке программы отдельно на рабочие места обновите каждое из них. Если программа запускается из одной общей папки, обновите эту папку при закрытых клиентах.

**Первая установка:** скачайте [полный ZIP из main](https://github.com/ilushenssss/local-kanban-service/archive/refs/heads/main.zip), распакуйте и запустите `Create-shortcut.vbs`. В main находятся встроенный Python и библиотеки. Лёгкий архив сам по себе не содержит готового окружения для первого запуска.

Ветка updates сейчас использует то же окружение, что main: Python 3.8.10 x64 и PyQt5 5.15.11. Если в будущем изменятся зависимости, сначала потребуется обновить окружение из полной поставки.

## Совместная работа

Можно разместить всю программу в общей папке, например `\\server\Общие\Канбан`: клиенты запускают встроенный Python оттуда, данные создаются в соседней `data/`. Сотрудникам нужны права чтения/записи/создания/удаления в папке данных.

Или скопируйте программу на каждое рабочее место. Скопируйте `kanban.ini.example` в `kanban.ini` и задайте **один общий UNC-путь** к данным у всех клиентов. Сохраните INI как UTF-8. Без INI программа использует `data/` рядом с собой.

SQLite открывается напрямую через общую папку — файловая архитектура согласована пользователем. Запись защищена общей блокировкой и транзакциями; версии задач предотвращают молчаливую перезапись. Но сбои SMB и сети сохраняют риск повреждения SQLite. Требуется надёжная сетевая папка и регулярное резервирование. Не используйте Windows Offline Files, облачную синхронизацию или WebDAV для живой базы.

## Возможности

Общие поля, кнопки, таблицы, вкладки и тёмная боковая панель используют исходную тему ветки `electronic-document-management-system/pyqt-desktop`. Дополнительные формы Канбана оформлены теми же контролами.

- Доски: создать, переименовать, архивировать.
- Колонки: названия, порядок, колонка завершения, необязательный лимит с предупреждением.
- Задачи: исполнители, приоритет, метки, срок, описание, чек-лист, комментарии, вложения и история. Перетаскивание и команда «Переместить в…», копирование, архивирование и восстановление.
- Поиск по всей БД, фильтры и обновления коллег без сброса открытой формы.
- Конфликты с сохранением текста, безопасные повторы записи, резервирование SQLite и вложений.

Карточка открывается двойным щелчком. После успешного сохранения карточка закрывается; при ошибке, конфликте или оставшихся неотправленных данных она остаётся открытой.

- **Сотрудники:** кнопка «Сотрудники…» слева или «Справочник…» у исполнителей. Укажите имя пользователя Windows и отображаемое имя; существующему сотруднику можно изменить отображаемое имя. Это не добавляет пароли или роли.
- **Исполнители:** обычный выпадающий список, как в pyqt-desktop. Выберите сотрудника — он появится в списке выбранных под полем. Можно добавить нескольких; для удаления выделите сотрудника и нажмите «Убрать».
- **Метки:** «Метки доски…» добавляет метки в общую БД. В задаче они добавляются обычным выпадающим списком и отображаются под ним. Чтобы снять метку, выделите её и нажмите «Убрать». Метки привязаны к доске.
- **Срок:** компактное поле даты с обычным выпадающим календарём, как в pyqt-desktop. Календарь открывается сразу, без дополнительного флажка. «Сбросить» убирает срок; пустое поле показывает «Без срока». При открытии пустого срока календарь показывает текущий месяц, отмена выбора не назначает дату.
- **Чек-лист:** введите пункт и нажмите «Добавить» или Enter. Отмечайте выполненное флажками; двойной щелчок редактирует текст. «Убрать пункт» удаляет выбранный пункт до сохранения. Текст в поле нового пункта также включается при сохранении задачи.
- **Приоритет:** низкий — серый, обычный — синий, высокий — янтарный, срочный — красный; подпись всегда видна, поэтому значение определяется не только цветом.
- **История:** автор, дата и понятные названия изменённых полей с прежними и новыми значениями. Время истории — UTC.

При создании задачи нет поля «Переместить в…»: новая задача попадает в первую колонку доски. Перемещение доступно для сохранённых задач. Для комментариев и вложений сначала сохраните задачу, затем откройте её снова. Одинаковые имена вложений не приводят к замене файлов.

Для обновления закройте приложение у всех сотрудников, сделайте резервную копию и замените файлы программы. Сохраните свою папку `data/` и `kanban.ini`; архив GitHub их не содержит. Справочники используют существующие таблицы `users` и `labels`, новую базу создавать не нужно.

## Что входит

```text
Create-shortcut.vbs    создание ярлыка на рабочем столе
main.pyw               точка входа
kanban/                код приложения
environment/python/   сохраняется от полной установки main; в ветке updates отсутствует
kanban.ini.example     пример общей папки данных
requirements/          закреплённые версии зависимостей
docs/                  инструкции и результаты проверок
tools/                 обслуживание и воспроизводимая сборка
tests/                 автоматические проверки
```

Встроено: Python 3.8.10 x64, PyQt5 5.15.11, Qt 5.15.2, PyQt5-sip 12.15.0 — по образцу ветки `pyqt-desktop`. Из Qt оставлены Core, Gui, Widgets и Test для проверок; лишние модули, инструменты сборки Python и посторонние приложения удалены. Сохранены необходимые DLL, платформенные плагины и лицензии. Условия лицензирования зависимостей находятся в окружении; PyQt5 распространяется по GPL/commercial.

Целевые ОС — Windows 10/11 x64. Окружение выбрано также для совместимости с Windows 7 SP1/8.1 x64 (нужны KB2533623 и KB2999226), но запуск в Windows здесь не проверялся. Python 3.8 выбран по образцу, несмотря на завершение его поддержки.

## Обслуживание и разработка

[Резервирование, восстановление и обновление](docs/OPERATIONS.md) · [Архитектура](docs/ARCHITECTURE.md) · [Проверки и ограничения](docs/VALIDATION.md).

При аварии не удаляйте `kanban.lock` по возрасту: администратор сначала закрывает все клиенты и проверяет, что запись нигде не идёт. Не удаляйте журналы SQLite. При конфликте используйте сравнение версий в карточке. Несохранённые данные остаются в открытой форме, но не переживают аварийное закрытие приложения.

Пересборка окружения выполняется **только разработчиком на компьютере с интернетом**, не при обычном запуске: `python tools/build_windows.py`. Все загружаемые пакеты проверяются по закреплённым SHA-256. Перед пересборкой сохраните старое `environment/python` вне репозитория: скрипт не заменяет существующую папку. `tools/trim_windows.py` оставляет нужные модули. Дополнительный ZIP: `python tools/package_windows.py NEW_ARCHIVE.zip`.

Проверки Windows:

```text
environment\python\python.exe -m unittest discover -s tests -v
```

Проверки Linux (отдельное окружение, не Windows-библиотеки):

```sh
python -m venv .venv
.venv/bin/python -m pip install -r requirements/runtime.txt
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests -v
```
