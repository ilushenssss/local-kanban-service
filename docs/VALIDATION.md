# Проверки версии 2.1

Среда: Linux, Python 3.12, PyQt5 5.15.11 / Qt 5.15.2. Windows, ярлык/VBS и реальная SMB-сеть здесь не проверены.

- `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests`: 47 тестов проходят.
- Хранилище: создание/изменение/архив/восстановление, поиск, справочники, завершение, конфликты, повтор UUID, вложения, backup/restore, четыре параллельных процесса на локальном Linux-диске.
- Удаление колонок: перенос активных и архивных задач с историей, завершение/повторное открытие, конфликт устаревшей карточки, безопасный повтор операции, откат при ошибке, запрет неверного плана, защита от повторного использования удалённых ID.
- QtTest: реальные нативные списки исполнителей/меток (мышь/клавиатура), календарь, чек-лист, сохранение с закрытием, сохранение ввода при ошибке/конфликте, подтверждение удаления колонки, создание задачи в выбранной колонке.
- Статистика учитывает всю доску при пустой поисковой выборке; переключение и сохранение тёмной темы, цветные значки меток, календарь в тёмной теме.
- Снимки Qt offscreen: доска в обеих темах, узкое окно, карточка, календарь, статистика. Снимки создаются тестами в игнорируемом docs/screenshots; это проверка Linux-виджетов, не Windows.

Автоматические проверки не заменяют пользовательскую оценку удобства и проверку рабочего SMB-сервера. Роли по согласованию отсутствуют. Цвета меток автоматические; ручной редактор цвета не добавлен. Статистика — текущее состояние, без временных графиков.

Обновление при переносе: QtTest имитирует вложенный цикл QDrag.exec_, доставляет ответ уже запущенного чтения во время переноса и завершает запись до выхода из цикла. Проверяется сохранность исходного виджета/карточки, перенос после завершения, отмена переноса и отсутствие пересоздания при неизменившихся данных. Нативный drag-and-drop в Windows не проверен.

Графики: проверены непересекающиеся сегменты кольца, доля завершения, сумма колонок и сегменты нагрузки, пустая доска; сняты и просмотрены Qt offscreen изображения светлой и тёмной темы. Графики QPainter не требуют новых пакетов.

QtTest 1.4: отсутствие поля переноса, хронологическая история, собственные и чужие сообщения, экранирование HTML в комментариях. Снимки компактной доски и переписки просмотрены в Linux offscreen.

QtTest 1.5: верхние вкладки двух досок и переключение, полный список личных назначений на другой доске, исключение чужих задач, поиск, открытие личной задачи с правильными колонками. Снимки новых карточек, двухколоночной формы и личного списка просмотрены. Все 47 тестов проходят в Linux; Windows и SMB не проверены.

Проверки 1.6: независимые и сохраняемые отметки прочтения двух сотрудников; монотонность, отказ при неверной задаче, неизменность версии задачи. QtTest проверяет сворачивание панели, дерево досок, список/Гант, постоянный чат с системными событиями, отметку чтения, сохранность черновика и текста сообщения, вертикальную компоновку на узком окне. Просмотрены светлые/тёмные снимки, широкая/узкая форма. Нативный выбор справочников проверяется после прокрутки до поля. Работа в Windows и на SMB здесь не проверена.

Проверки 2.0: новая шапка/переключатель видов, отсутствие старых видимых вкладок, синхронизация вида, дерево «Проект / Доска», реалистичная временная доска из четырёх колонок с задачами, стикерами, прогрессом и четырьмя непрочитанными сообщениями. Снимки нового интерфейса просмотрены в Linux offscreen. Шрифт — визуально близкий Arial с Liberation Sans fallback, не извлечённая из изображений гарнитура.

Проверки 2.1: миграция существующей v1 с сохранением задач, общий чат двух Store/login, счётчики прочтения, монотонные отметки, безопасный повтор и backup/restore сообщений. QtTest: первое открытие в конце длинного обсуждения, сохранение позиции чтения, возврат на ту же доску, отсутствие общей QScrollArea формы, только одна видимая кнопка в свёрнутой панели, бейдж общего чата/открытие/сворачивание. Имитация потери связи после записи общего сообщения: повтор не дублирует запись и сохраняет новый текст. Снимки светлой/тёмной доски, формы и общего чата просмотрены в Linux offscreen. Windows и реальная SMB-сеть не проверены.
