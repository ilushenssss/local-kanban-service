# Проверки версии 1.3

Среда: Linux, Python 3.12, PyQt5 5.15.11 / Qt 5.15.2. Windows, ярлык/VBS и реальная SMB-сеть здесь не проверены.

- `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests`: 38 тестов проходят.
- Хранилище: создание/изменение/архив/восстановление, поиск, справочники, завершение, конфликты, повтор UUID, вложения, backup/restore, четыре параллельных процесса на локальном Linux-диске.
- Удаление колонок: перенос активных и архивных задач с историей, завершение/повторное открытие, конфликт устаревшей карточки, безопасный повтор операции, откат при ошибке, запрет неверного плана, защита от повторного использования удалённых ID.
- QtTest: реальные нативные списки исполнителей/меток (мышь/клавиатура), календарь, чек-лист, сохранение с закрытием, сохранение ввода при ошибке/конфликте, подтверждение удаления колонки, создание задачи в выбранной колонке.
- Статистика учитывает всю доску при пустой поисковой выборке; переключение и сохранение тёмной темы, цветные значки меток, календарь в тёмной теме.
- Снимки Qt offscreen: доска в обеих темах, узкое окно, карточка, календарь, статистика. Снимки создаются тестами в игнорируемом docs/screenshots; это проверка Linux-виджетов, не Windows.

Автоматические проверки не заменяют пользовательскую оценку удобства и проверку рабочего SMB-сервера. Роли по согласованию отсутствуют. Цвета меток автоматические; ручной редактор цвета не добавлен. Статистика — текущее состояние, без временных графиков.

Обновление при переносе: QtTest имитирует вложенный цикл QDrag.exec_, доставляет ответ уже запущенного чтения во время переноса и завершает запись до выхода из цикла. Проверяется сохранность исходного виджета/карточки, перенос после завершения, отмена переноса и отсутствие пересоздания при неизменившихся данных. Нативный drag-and-drop в Windows не проверен.

Графики: проверены непересекающиеся сегменты кольца, доля завершения, сумма колонок и сегменты нагрузки, пустая доска; сняты и просмотрены Qt offscreen изображения светлой и тёмной темы. Графики QPainter не требуют новых пакетов.
