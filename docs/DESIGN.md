# Канбан — визуальный контракт

## Overview

По последнему указанию пользователя ориентир — канбан YouGile: компактная навигация, цветные заголовки колонок и карточки с краткими сведениями. Это самостоятельная реализация на PyQt5, без ресурсов YouGile и внешних шрифтов. Предыдущее требование копировать pyqt-desktop заменено новым направлением.

## Colors

Источник — LIGHT/DARK в kanban/theme.py. TOKENS обновляется на месте, чтобы рисованные карточки и история получали ту же тему. Светлая: белые поля, фон #f5f6f8, панель #263345, текст #202c40, рамки #bdc9da, акцент #315dcc. Тёмная: фон #151d2b, поля #202b3c, текст #edf2fa, рамки #50617a. Заголовки колонок получают пять пастельных цветов по порядку. Приоритеты подписаны; просрочка обозначена текстом. Цвет метки стабильно вычисляется из имени SHA256/HSL, одинаков на компьютерах; пользовательский выбор цвета пока отсутствует.

## Typography

Локальный системный шрифт Qt/Fusion: основной 10pt, заголовок 18pt, карточка 10.5pt, метаданные 9pt. Подписи полей полужирные, над контролом.

## Layout

Навигация 210px. Вкладки «Доска» и «Статистика». Поиск и быстрые фильтры доступны сразу; дополнительные параметры раскрываются кнопкой с количеством активных фильтров. Есть сброс. Доска прокручивается горизонтально, колонки вертикально. Каждая колонка имеет отдельную рамку, цветной заголовок и кнопку добавления задачи. На небольшом окне сохраняется прокрутка. Строка состояния видна на обеих вкладках.

## Elevation & Depth

Тонкие границы вместо теней. Карточки отделены от подложки. Выделение и клавиатурный фокус контрастны в обеих темах.

## Shapes

Колонки 10px, карточки 8px, контролы 6px. Нативные Qt popup и календарь получают общую палитру. Полосы прокрутки имеют общую палитру и видимый ползунок.

## Components

RegistrySelection — обычный combo с перечнем выбранного; метки снабжены цветными значками. DateField — QDateEdit с русским календарём и очисткой. ChecklistEditor — редактируемый список. TaskDialog сохраняет черновик при ошибках и закрывается после успешной записи. ColumnsDialog использует флажок завершения; удаление запрашивает получателя задач и подтверждение, применяется только по сохранению. StatisticsPage показывает все активные задачи доски и явно сообщает правила подсчёта исполнителей. Тема сохраняется локально через QSettings, применяется ко всем открытым окнам и при следующем запуске.

## Do's and Don'ts

Общие контролы и палитра едины для всех окон. Текст и формы не сбрасываются при обновлении коллег. Не добавлять удалённые ресурсы, анимации, которые мешают работе, или новые системы входа.

## Reconcile drift

Новый ориентир YouGile заменяет побайтовую копию стиля pyqt-desktop. Поведение надёжных нативных списков и календаря сохранено. Проверки — tests/test_ui.py, снимки Linux offscreen. Windows и SMB требуют отдельной проверки.

## Графики статистики 1.3

Общий Chart в kanban/charts.py рисует сглаженные диаграммы средствами QPainter без дополнительных библиотек. Кольцо: завершённые, открытые непросроченные и просроченные — взаимоисключающие категории. Полосы колонок нормированы к максимальному количеству, нагрузка — составные полосы завершённых/просроченных/прочих открытых. Значения подписаны; цвет дополнен текстом и точными таблицами. Пустая доска показывает объяснение вместо фиктивных долей. Палитра поверхностей общая для светлой и тёмной темы. Длинные подписи сокращаются на графике, полные доступны в подсказке и таблицах.

## Уплотнение интерфейса 1.4

Минимальная ширина колонки 244px, высота карточки 154px. Название 9.5pt, метаданные 8.5pt. Завершённые задачи приглушены до opacity 0.57, заголовок зачёркнут. Перенос исключён из формы: скрытый combo хранит состояние для совместимости; перенос доступен перетаскиванием и контекстным меню. Нижние кнопки открытия, переноса и копирования убраны. Постоянная справка о таймере не выводится, строка обратной связи скрыта, когда пуста. История — по возрастанию даты/id. Комментарии — сообщения: свои справа с подписью «Вы», чужие слева; автор, время и экранированный текст. Обновление сохраняет позицию прокрутки, новые сообщения прокручиваются вниз, если пользователь уже находился внизу.

## Макет по изображениям пользователя 1.5

QTabBar досок расположен над рабочей областью; боковая панель содержит навигацию и команды. «Мои задачи» — отдельная вкладка со списком назначений по всем активным доскам; доступны поиск, доска, состояние, приоритет. Строка показывает расположение задачи и открывает TaskDialog с колонками её собственной доски. Архивные задачи/доски исключены.

Колонки шириной 300px, цветная верхняя граница, добавление сразу под заголовком, высота содержимого ограничена с внутренней прокруткой. Карточки 116px, с чек-листом 136px: название и индикатор завершения сверху, приоритет/дата/метка компактным рядом, инициалы исполнителя справа, прогресс чек-листа снизу. Остальные сведения доступны в подсказке/открытой форме. Фотографии не используются: данных о них нет. Завершённые карточки приглушены и зачёркнуты.

TaskDialog 960×690: описание и чек-лист слева, свойства справа; общая прокрутка и закреплённые действия. Нативные контролы и сохранение черновиков сохранены.

## Действующий бриф 1.6 — настольное приложение

Пользователь подтвердил PyQt5 после веб-брифа. Канонические актуальные цвета: фон #F4F5F7, поверхности и sidebar #FFFFFF, текст #1E293B, вторичный #64748B, границы #E2E8F0, акцент #2563EB. Источник — LIGHT в theme.py; тёмная тема остаётся. Эти значения заменяют прежние светлые токены разделов 1.4–1.5.

Sidebar 240px сворачивается до 64px. Дерево содержит существующие доски в группе «Рабочие доски»: проектов как отдельных сущностей в данных нет. Профиль показывает текущий Windows login. Команды доски объединены меню. Header 56px; поиск в нём на широком окне и отдельной строкой на узком. Виды: Канбан, Список, Диаграмма Ганта, Сводка, Мои задачи. Гант — только просмотр существующих дат, без зависимостей и редактирования длительности. Для сроков раньше создания полоса охватывает обе даты, подсказка содержит их исходный смысл.

Карточки: заголовок ограничен двумя строками; стикеры, срок, инициалы, чек-лист и действительное число непрочитанных чужих сообщений. Новая задача добавляется внизу колонки. Клик открывает окно задачи. Завершение остаётся приглушённым и зачёркнутым.

Окно задачи: форма слева, чат справа; QSplitter позволяет менять пропорции. При ширине менее 1000px части идут вертикально. Чат объединяет комментарии и системные события истории хронологически. Поле ввода закреплено снизу, сообщения экранируются. Отметка прочтения отправляется только для видимого чата, прокрученного вниз; ошибки отметки не стирают форму и повторяются при следующем обновлении. Вложения и отдельная история доступны вкладками. Черновики и UUID повторов сохранены.

Установка, ярлык и встроенный Python прежние. Демонстрационные записи не добавляются в рабочую БД.

Новые доски из интерфейса получают колонки «Бэклог», «В работе», «На проверке», «Готово». Колонки существующих досок сохраняются.
