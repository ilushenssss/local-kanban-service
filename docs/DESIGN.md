# TeamSync — новый интерфейс 2.0

## Overview

Цель текущей переработки — три предоставленных HTML-макета: доска, карточка «Задача», карточка «Чат». Макет главнее описания. Приложение остаётся офлайн PyQt5 с существующей SQLite и поддержкой общего каталога. Надпись о хранении данных только на этом устройстве не использовать. Явное сохранение и история остаются в общем стиле.

Переработка выполняется по этапам с показом снимков. Текущий этап — базовые компоненты; компоновка экранов ещё не перенесена.

## Colors

Исполняемый источник — LIGHT/DARK, STICKERS и AVATAR_COLORS в kanban/theme.py (модель B). Документ отражает утверждённые значения, QSS и QPainter потребляют эти токены. Светлая тема: фон #F4F5F8, поверхность #FFFFFF, текст #1B1F2A, вторичный #4A5264, приглушённый #5E6678; граница #E3E6EC, поля #D5D9E2, акцент #122C34. Выбор #E7EFF0/#122C34. Опасное действие #9B1C1C/#F3C6C6. Свойства #F7F8FA, колонка #E8EAF0. Тёмная тема сохраняет читаемые семантические варианты.

Стикеры используют пять пар эталона с детерминированным назначением по полному SHA-256 имени. Значения в БД не изменяются. Аватары #122C34, #C2410C, #0F766E с белым текстом.

## Typography

Локальные Inter Regular/Medium/SemiBold/Bold (400/500/600/700) получены из вложенных в макет лицензированных подмножеств Latin/Cyrillic; объединены в статические TTF для Qt5. Исходная лицензия — kanban/assets/fonts/OFL.txt. Сетевые запросы при запуске не нужны. Проверена поддержка латиницы и кириллицы всеми четырьмя начертаниями. Базовый текст 14px; мета 12–13px; подписи 11px капсом; доска 20px; название задачи 24px. Последние размеры применяются на этапах экранов.

## Layout

Целевая панель 248px, шапка 64px, вкладки 48px, колонки 296px с gap 16px. Карточка 960×800, шапка 56px, свойства 280px справа. Узкие экраны от 390px: панель сворачивается, карточка полноэкранная, свойства под контентом. Компоновка ещё находится в очереди реализации.

## Elevation & Depth

Целевая тень карточки 0 1px 2px rgba(20,25,40,.08); перенос 0 10px 24px rgba(20,25,40,.2) с поворотом 2°. Модальное окно 0 24px 64px rgba(0,0,0,.35) на фоне #3A3F4E. Не вводить декоративные эффекты.

## Shapes

Кнопки и поля 8px, стикеры 6px, карточки 10px, колонки 12px, пузыри 14px. Окно 16px. Поле сообщения и отправка — исключение 22px по макету. Аватары круглые.

## Components

Токены → stylesheet() → существующие Qt controls; CardDelegate потребляет общие палитры напрямую. Кнопки primary/neutral/danger имеют hover, pressed, focus и disabled; толщина рамки не меняется при фокусе. Высота стандартной кнопки не менее 36px; компактные иконочные исключения будут перенесены с экранной компоновкой. Фокус виден без сдвига геометрии. Интерфейс без новых анимаций, поэтому режим ограничения движения соблюдается без дополнительной настройки.

RegistrySelection, DateField, ChecklistEditor и фоновые операции остаются существующими владельцами поведения. Не подменять дату временем, архивирование удалением, статистику календарём. Не показывать фиктивные операции. Общий чат, история, справочники, приоритет и сохранение должны остаться доступны.

## Do's and Don'ts

Не менять Store/схему БД ради дизайна. Не загружать шрифты из сети. Не добавлять зависимости. Тестовые данные — только во временной БД. Не скрывать ошибки, конфликты и несохранённые данные. Не делать заглушки кнопок из отсутствующих возможностей макета.

## Verification

Для каждого этапа: unittest discover, compileall изменённых модулей, Qt offscreen снимки и визуальное сравнение. Frontend-сборка/TypeScript не настроены, не заявлять их выполнение. Windows и реальная SMB-сеть требуют отдельной проверки. Базовые цвета проверяются на контраст 4.5:1; все состояния требуют проверки по мере переноса экранов.

## Текстовый интерфейс — уточнение пользователя

Декоративные значки, эмодзи, аватары и цветные точки не используются. Действия обозначаются словами, в том числе «Меню», «Настройки», «Изменить», «Свернуть», «Общий чат» и «Очистить поиск». Число новых сообщений показывается текстом. Нативные стрелки выпадающих списков и флажки остаются механизмами управления; диаграммы — представлением данных. В форме задачи исполнители и метки выбираются из существующих выпадающих списков, без переходов в справочники. Справочники доступны отдельно из основного окна.


Стрелки выпадающих списков: локальный PNG-шеврон 12×8px, линия 1.6px с круглыми концами; общая область нажатия справа 32px, без системной выпуклой рамки. QComboBox и QDateEdit используют один стиль; цвет зависит от темы и состояния. Это функциональный индикатор раскрытия, согласованный отдельным запросом пользователя; декоративные значки не возвращаются.


## Уточнения интерфейса от 16 ноября 2026

По явному запросу пользователя разрешены функциональные значки чата и hamburger-меню, а также сгенерированный логотип TeamSync рядом с названием. Прочие декоративные значки не возвращаются. Кнопки «Изменить» у колонок удалены; настройка колонок доступна из общего меню настроек. Форма и свойства используют одинаковые верхние отступы, поля и выравнивание подписей. PrioritySelector — нативные взаимоисключающие радиокнопки; компактный PriorityCombo остаётся только фильтром доски. Логотип поставляется локальным PNG; генерация или сеть при запуске не требуются.


## Выпадающий календарь

DeadlineCalendar остаётся нативным QCalendarWidget с общей палитрой темы. Шапка без системной синей заливки, локальные PNG-стрелки; сетка от понедельника без номеров недель. Выбранный день — акцентная поверхность с радиусом 8px, сегодняшний день — тонкая акцентная рамка; соседние месяцы приглушены. Минимальный размер 308×300px, текст дня 13px. Светлая и тёмная темы используют TOKENS через refresh_palette и paintCell. Клавиатурный выбор и Escape сохраняются.


## Растровые ресурсы и новый акцент

Основной акцент заменён на #122C34; hover #1C414B, pressed #0C2026; светлое выделение #E7EFF0. Для тёмной темы выделение и фокус имеют более светлый родственный тон #9DC5CB ради контраста. Значки управления и стрелки поставляются PNG, без зависимости от SVG-плагина в Windows. Меню, чат и логотип получены генерацией и подготовлены к малому размеру. Логотип упрощён до компактного знака без текста. Вкладки используют одинаковую насыщенность и ширину во всех состояниях; при нехватке места доступны стрелки прокрутки и многоточие.
