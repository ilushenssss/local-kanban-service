# Канбан — визуальный контекст

## Overview

Настольная рабочая доска отдела в духе Notion: спокойные поверхности, сильная текстовая иерархия, ровные карточки. Регистp продукта — рабочий инструмент, не маркетинговый экран. Русскоязычные пользователи Windows, мышь и клавиатура. Новое оформление по запросу пользователя улучшает иерархию существующего интерфейса; не меняет файловую архитектуру.

Запоминающийся элемент — компактный подписанный бейдж приоритета в правом верхнем углу карточки, рядом с коротким номером слева. Вся остальная графика подчинена задаче и не конкурирует с содержанием.

## Colors

Канонический исполняемый источник — `kanban/theme.py:TOKENS` и `PRIORITIES`. `stylesheet()` переводит токены в Qt QSS, `CardDelegate` и `PriorityCombo` читают те же цвета напрямую. История использует общий muted. Документ фиксирует назначение; при изменении токенов обновляется вместе с кодом.

Основные цвета определены во frontmatter. Primary во frontmatter соответствует runtime accent. Дополнительно: hover #edf1f7, selection #edf4ff, danger #ac343a, scroll #bec4cd, accent_hover #2057b9. Семантические пары текста/фона приоритетов: низкий #617086 / #edf0f4, обычный #2865cf / #eaf1ff, высокий #94600a / #fff4da, срочный #ac343a / #fdecee. Подпись обязательна — цвет не является единственным сигналом. Просрочка всегда содержит слово «Просрочено».

## Typography

Локальный Segoe UI и резерв DejaVu Sans. Текст 13px; заголовки окон 25px semibold; заголовок задачи 19px semibold. Карточки: название 14px semibold, метаданные 11px. Никаких скачиваемых шрифтов.

## Layout

Боковая панель 220px. Рабочая область с полями 24px, интервалы 12–14px. Колонки от 292px, карточка 194px высотой; длинное название переносится на две строки, полный текст доступен в подсказке и карточке. Доска прокручивается горизонтально, задачи вертикально; положение прокрутки сохраняется при обновлении. Форма прокручивается независимо, действия сохранения/закрытия находятся снаружи. Создание не показывает перенос и пустые даты создания.

## Elevation & Depth

Плоские белые карточки на светло-сером холсте, тонкие границы; тени и анимация не используются. Наведение усиливает границу, выбранная карточка получает синий контур и светлое выделение. Кнопка сохранения и создания — единственные яркие действия в своих областях.

## Shapes

Контролы 6px, карточки 9px, бейджи 5px. Скругления не превращают рабочие поля в декоративные плашки. Внешние ресурсы отсутствуют; стрелка списка — маленький локальный PNG в `kanban/assets/`.

## Components

`CheckComboBox` — единый список с множественным выбором для исполнителей и меток. `DateField` — необязательный срок с русским Qt-календарём. `ChecklistEditor` — список редактируемых пунктов и флажков. `PriorityCombo` и `CardDelegate` разделяют семантику приоритетов. `TaskDialog` владеет формой, `CatalogDialog` — справочниками. Кнопки делятся на primary, neutral, quiet; disabled и focus одинаковы во всех окнах. Полосы прокрутки видимы и оформляются глобально.

## Do's and Don'ts

Использовать подписанные поля, понятные ошибки, клавиатуру и сохранение черновика при конфликте. Не использовать внешний интернет, градиенты, большие тени, бесконечные анимации или цвет без текста. Не показывать JSON и внутренние ID в истории. После успешного сохранения закрывать карточку, при ошибке сохранять её и текст.

Снимки и QtTest — `tests/test_ui.py`. Проверка Windows, экранного диктора и высокой контрастности остаётся отдельной; Linux offscreen её не заменяет.
