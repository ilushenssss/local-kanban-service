# Переработка интерфейса: согласованный визуальный бриф

Источник: последний запрос пользователя. Пользователь подтвердил: сохраняется настольное приложение PyQt5. Веб-стилистика реализуется нативными виджетами; браузер, веб-сервис и новые зависимости не нужны.

## Визуальные токены

| Назначение | Значение |
|---|---|
| Рабочая область | #F4F5F7 |
| Панели, карточки, sidebar | #FFFFFF |
| Основной текст | #1E293B |
| Вторичный текст | #64748B |
| Граница | 1px solid #E2E8F0 |
| Акцент | #2563EB |
| Стикеры | мягкие зелёный, янтарный, коралловый, фиолетовый |

Информационная плотность достигается компоновкой и уменьшением пустых областей, а не нечитаемым мелким шрифтом. Свои шрифты, аватары или изображения из интернета не загружаются.

## Навигация

Боковая панель 240px, сворачиваемая. Вверху логотип; основной блок — дерево существующих досок. Модель проектов в текущей БД отсутствует: не создавать фиктивные связи досок с выдуманными проектами. Внизу «Мои задачи», «Отчёты», «Сотрудники», профиль с текущим именем пользователя. Верхняя панель 56px: название доски, виды, поиск, фильтры, добавление задачи. На небольшом окне фильтры раскрываются отдельно.

## Доска и карточки

Горизонтальная прокрутка, колонки с верхней цветной полосой 3px, счётчиком и добавлением внизу. Названия существующих колонок сохраняются. Пример четырёх колонок — только для новой демонстрационной доски, без изменения данных пользователя.

Карточка: заголовок до двух строк, стикеры, чек-лист, непрочитанные сообщения, срок, инициалы исполнителей. Полное название доступно в открытой задаче и подсказке. Завершённые задачи сохраняют приглушённое зачёркнутое оформление. Просрочка обозначена текстом/значком.

## Задача и переписка

Панель справа: две части, свойства и чек-лист слева, переписка справа. На узком окне части располагаются последовательно. Сообщения идут хронологически; поле ввода закреплено внизу. Обычные сообщения и события истории различаются оформлением. Пользовательский текст всегда экранируется. События берутся из существующей неизменяемой истории.

Форма сохраняет введённое при сетевой ошибке и конфликте. Закрытие несохранённого требует предупреждения. Повтор отправки использует прежний UUID. Фоновое обновление не пересоздаёт открытую форму и не меняет набранное сообщение.

## Непрочитанные

Счётчик должен показывать действительные непрочитанные комментарии, не их общее число. Нужна сохранённая отметка последнего прочитанного комментария отдельно для каждого пользователя и задачи. Своё отправленное сообщение не помечается непрочитанным. Демонстрационные значения не подставляются в рабочие данные.

## Виды

Канбан, список и существующая статистика используют одни данные и фильтры. Диаграмма Ганта запрошена как новый вид; если реализуется, отражает текущие даты создания и сроки, без выдуманных зависимостей и длительностей. Отсутствие срока явно обозначается.

## Проверка

Переключение досок, открытие задачи и чата, создание в выбранной колонке, отправка сообщения и безопасный повтор, интерактивный чек-лист, конфликт и сохранение черновика, непрочитанные, сворачивание навигации, узкое окно, обе темы. Отдельно проверить отсутствие регрессии обновления при перетаскивании. Реалистичные примеры добавляются только в тестовые данные или отдельный демонстрационный режим.
