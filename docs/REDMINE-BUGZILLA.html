1. Загрузка исходной ТИ

Первый этап

Пример из макета: ID задачи Redmine 23018 соответствует карточке ТИ-1157.

  1. TeamSync · форма

    «Новая задача»

    Пользователь вводит только ID из адреса /issues/23018.

    ID 23018
    Python · фоновый поток PyQt

    Чтение задачи

    Redmine(url, username=login, password=password), rm.auth(), затем rm.issue.get(23018).

    Запрос по ID 23018
    Redmine · исходная задача

    ТИ #23018

    Ответ содержит номер ТИ, заголовок, статус, согласования, основание и баги.

Если исходная задача недоступна или не найдена, TeamSync показывает причину в форме и не создаёт карточку.

3. КРИС_ТИ → подзадачи → прогресс

После успешной загрузки ТИ Python ищет КРИС_ТИ по ID исходной задачи. Подзадачи загружает по собственному ID найденной КРИС_ТИ. В этом примере 23018 ведёт к КРИС_ТИ #7200.

  1. Вход из маршрута 1

    ID исходной ТИ

    Из формы «Новая задача» поступил ID 23018.

    ID 23018
    Python · поиск в Redmine

    Проверить «Расположение ТИ»

    Искать в проекте КРИС_ТИ точное совпадение ID. Если значение хранит URL, извлечь ID из ссылки.

    Найденная задача
    Результат поиска Redmine

    КРИС_ТИ #7200

    Поле «Расположение ТИ» указывает на /issues/23018. ID 7200 передаётся в следующий шаг.

  2. Результат предыдущего шага

    ID родителя КРИС_ТИ

    7200 — ID родительской задачи для запроса её подзадач.

    parent_id = 7200
    Python · чтение подзадач

    Получить все статусы

    rm.issue.filter(parent_id=7200, status_id="*") читает прямые подзадачи, включая закрытые.

    ID, название, статус
    Redmine · пример ответа

    Три прямые подзадачи

    #7201 и #7202 завершены. #7203 в работе.

  3. Вход из ответа Redmine

    Список и статусы подзадач

    Каждая подзадача учитывается по собственному ID.

    Три подзадачи
    Python · расчёт прогресса

    Посчитать завершённые

    Подсчитать завершённые и общее число. Передать исходный статус каждой подзадачи для детализации.

    2 из 3 и три статуса
    TeamSync · карточка и окно

    Блок «КРИС_ТИ»

    На карточке прогресс 2/3. В окне задачи виден статус каждой подзадачи.

Если КРИС_ТИ не найдена, недоступна или найдено несколько совпадений, поля исходной ТИ остаются доступными. Блок КРИС_ТИ показывает причину. Для найденной КРИС_ТИ с пустым списком отображается «Подзадач нет».

Что уточнить перед подключением
  • Подтвердить ID проекта КРИС_ТИ, ID поля «Расположение ТИ» и формат его значения. Для Redmine также нужны технические ID полей номера ТИ, основания, согласований и списка багов.
  • Согласовать отображение неизвестных статусов ТИ, набор завершённых статусов КРИС_ТИ и необходимость учитывать вложенные уровни подзадач.
  • Для Bugzilla подтвердить техническое имя поля «Номер ТИ» и способ поиска по нему в вашей установке.
Обновление и область дальнейшей интеграции
  • Обновление повторяет запросы чтения. При ошибке загрузки уже открытой карточки TeamSync показывает время последнего успешного получения данных, если оно известно.
  • «Страница текущей версии», «Неосмеченные баги и СП», «Страница ИД», СППИ ЛиП и согласование отдельных приложений требуют уточнения источников данных.
