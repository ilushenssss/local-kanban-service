# Контракт поведения

Источник бизнес-решений: `docs/ARCHITECTURE.md`, согласованные пользователем требования. Роли и проверка входа отложены, архивирование вместо удаления. Никаких серверных разрешений в файловой версии нет.

| Capability | Canonical owner | Source of truth | Allowed variants | Verification |
|---|---|---|---|---|
| Table Selection | QListWidget / QTableWidget Qt | этот контракт | одна задача; строка колонок | tests/test_ui.py |
| Select/Listbox | RegistrySelection / PriorityCombo / QComboBox | этот контракт | native Qt popup, добавление в перечень выбранного | tests/test_ui.py |

Создание и изменение задачи используют одну форму, после успешного сохранения она закрывается. Комментарии/вложения требуют сохранённой задачи. Редактирование блокируется только на время её операции; размеры и названия кнопок не меняются. Поля сохраняются при ошибке; повтор использует прежний UUID. Конфликт явно показывает текущую версию и сохраняет пользовательскую форму. Принятие новой версии как основы требует подтверждения, автоматического перезаписывания нет.

Закрытие и Escape предупреждают о несохранённых полях, комментарии, загрузках и неопределённом результате. Во время фоновой операции окно не закрывается. Долговременных черновиков на диске нет.

Архивирование доски/задачи подтверждается, по умолчанию выбрана отмена. Задачи можно восстановить через фильтр «Архив». Задачи физически не удаляются; история не очищается. Колонка удаляется только с выбором оставшейся колонки для всех её задач, включая архивные. Подтверждение по умолчанию — отмена; изменение применяется после сохранения настроек. Перенос и история атомарны; версия задачи повышается. Последнюю колонку удалить нельзя.

Поиск 300 мс, ответы старой выборки игнорируются. Точное имя исполнителя, точная метка, диапазон дат, приоритет и быстрые фильтры совместно применяются по БД. Текущий набор отображается полностью, прокрутка нативная. Открытые формы не заменяются при фоновом обновлении.

Весь принадлежащий приложению текст русский; нативные файловые диалоги и стандартные системные сообщения зависят от локали ОС. Время истории — UTC, срок — календарная дата. Просрочка обозначена словом «Просрочено». Ввод длинных полей доступен в прокручиваемой форме, управление перетаскиванием имеет кнопочную альтернативу.

Встроенные Qt controls владеют focus, keyboard, selection и popup; пользовательские HTML/ARIA-компоненты не применяются. Проверка окон, состояния ошибок, конфликта, клавиатуры и поиска — `tests/test_ui.py`. Полная проверка доступности в Windows не выполнена.


Справочники сотрудников и меток хранятся в общей БД. Добавление и изменение отображаемого имени сотрудника — `CatalogDialog`, login неизменен при переименовании. Удаления нет. Метки добавляются для текущей доски. Оба справочника используют RegistrySelection: обычный Qt combo по щелчку/стрелкам/Enter добавляет значение в расположенный ниже список выбранного, Escape отменяет выбор. Выбранное значение не предлагается повторно; «Убрать» снимает назначение/метку и возвращает её в выпадающий список. Никаких имён и меток через запятую в форме больше нет.

DateField: стандартный QDateEdit шириной 160 с русским выпадающим календарём по стрелке, без предварительного включения. «Без срока» означает отсутствие даты; «Сбросить» очищает её. Пустое поле открывает текущий месяц и не назначает дату при Escape. Отображение dd.MM.yyyy, хранение ISO date. ChecklistEditor: кнопка/Enter добавляет пункт, флажок отмечает, двойной щелчок редактирует, кнопка удаляет выбранное; незавершённый ввод включается при сохранении задачи. Enter в строке пункта не сохраняет задачу. При закрытии незавершённый пункт считается несохранёнными данными.

Создание задачи использует первую колонку доски без поля переноса. Перенос выполняется на доске перетаскиванием или контекстным меню; поле переноса в форме скрыто. Успех закрывает форму; ошибка и конфликт сохраняют её. Если после неопределённого commit внесены новые правки или остались неотправленный комментарий/файлы, подтверждение прежней записи не закрывает окно с этими данными.

История — экранированное читаемое представление неизменяемых событий, русские поля, текущие имена сотрудников/колонок, прежнее → новое, время UTC. Приоритеты подписаны и имеют отдельные семантические цвета в списках и на карточках.

Статистика не зависит от фильтров и исключает архивные задачи. Несколько исполнителей учитываются каждый отдельно. Тема локальная, светлая/тёмная; единая палитра распространяется на открытые формы.

Обновление доски: раз в 5 секунд читается актуальное состояние, но неизменившиеся данные не пересоздают виджеты. Во время QDrag обновления откладываются, включая результаты уже запущенного чтения. После выхода из цикла перетаскивания выполняется свежее чтение. Начало записи инвалидирует прежние ответы. QDrag не удаляет строки модели автоматически: перенос выполняет Store, после чего обновляется представление.

История отображается от старых событий к новым. Комментарии оформлены как переписка; автор определяется по login, не по отображаемому имени. Введённые строки экранируются перед HTML-отображением. Завершённые задачи имеют зачёркнутый заголовок и приглушённое содержимое. Пустая строка состояния не занимает место.

Версия 1.5: доски переключаются верхним QTabBar, идентификаторы сохранены в tabData; обновление без изменений не пересоздаёт вкладки. «Мои задачи» запрашивает назначения текущего login по всем активным доскам независимо от фильтров канбана. Личные поиск/фильтры действуют по полному набору назначений. Открытие строки получает колонки её доски асинхронно, выбранная доска не подменяет данные задачи.

Версия 1.6: sidebar сворачивается; клик на карточке открывает задачу с постоянным чатом рядом. На узком окне чат располагается ниже формы. Системные записи читаются из task_history и не редактируются. Счётчик показывает только непрочитанные чужие комментарии. Для отметки чтения используется максимальный ID из уже загруженного и видимого чата, а не ID новых сообщений, пришедших позже. Старые отметки не уменьшают текущую. Список и Гант используют тот же полный фильтр доски; диаграмма только для просмотра. Нативные popup и календарь остаются прежними.

Версия 2.0: скрытые QTabBar хранят идентификаторы досок для совместимости, но не отображаются. Вид выбирается через view_switch, синхронный с pages. Дерево — единственный видимый список досок, имена «Проект / Доска» группируются без новой модели данных. Основные фильтры видимы сразу, остальные раскрываются. Архивирование задачи в контекстном меню. Нижних растянутых кнопок нет.
