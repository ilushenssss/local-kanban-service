# Встроенное окружение Windows x64

`python/` включён в Git целиком и готов к офлайн-запуску. Python 3.8.10, PyQt5 5.15.11, Qt 5.15.2, PyQt5-sip 12.15.0. SQLite входит в Python. Отдельных приложений из журнала СЗ и его библиотек здесь нет.

Точка запуска: `python/pythonw.exe` с абсолютным путём к `main.pyw` в аргументе. Файл `python38._pth` ограничивает поиск модулей встроенным окружением и каталогом приложения; системный Python не нужен.

Qt: Core, Gui, Widgets; Test сохранён для автоматических проверок. Удалены QML, сеть Qt, мультимедиа, Designer, прочие неиспользуемые Qt-модули, заголовки Python, import-библиотеки и инструменты разработчика. Сохранены нужные Visual C++ DLL, платформенные/графические плагины и лицензии. pip оставлен для обслуживания без интернета.

`SHA256SUMS` содержит закреплённые хеши исходных официальных пакетов; `runtime-manifest.json` — хеши файлов готового окружения. Это проверка комплектности и изменения байтов, а не подтверждение запуска в Windows.

Пересборка: `tools/build_windows.py`; обрезка повторяемая: `tools/trim_windows.py`. Обычный запуск эти скрипты не вызывает и ничего не скачивает.
