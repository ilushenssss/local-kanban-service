# Словари орфографии

Русский ru_RU и английский en_US Hunspell из LibreOffice dictionaries. Точная ревизия, адреса источников и SHA-256 файлов записаны в SOURCES.json. Лицензии/авторство находятся в README_ru_RU.txt и README_en_US.txt; файлы .aff/.dic поставляются без изменений. Словоформы проверяются локальным Spylls, без загрузок при запуске и отправки текста в интернет.
