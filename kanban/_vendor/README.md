# Встроенный Spylls

Spylls 0.1.7 — офлайн-реализация Hunspell на Python, без дополнительных Python-пакетов. Источник: https://pypi.org/project/spylls/0.1.7/ (spylls-0.1.7-py2.py3-none-any.whl). Фактическая лицензия wheel — Mozilla Public License 2.0, сохранена в spylls/LICENSE (метаданные wheel отдельно указывают MIT, для поставки используется приложенный текст лицензии).

Из wheel включён Python-код, без его словарей/примеров. Изменения TeamSync: абсолютные импорты перенесены в kanban._vendor.spylls; файловые потоки закрываются при смене кодировки и после чтения .aff/.dic, включая ошибки. Исходный изменённый код поставляется вместе с приложением. Пользовательский текст не передаётся на серверы. Словари и их лицензии находятся отдельно в ../dictionaries/.
